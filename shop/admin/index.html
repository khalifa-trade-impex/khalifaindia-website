How saving works. This site is static — there is no server, so edits save to this browser only and are visible to you alone. They take effect immediately on the shop for testing. To publish them to real visitors, use Export for publishing below and send the JSON to your developer to paste into corsa-data.js. Nothing here is lost by closing the page.

Select a product from the list to edit it.

Bulk import — names, codes and MRP

Paste rows from Excel (copy the columns straight from the sheet) or type them. One product per line, columns separated by a tab or comma:

SKU 	 Product Name 	 MRP
SMF-2102 	 Bib Cock 	 350
SMF-2106 	 Angle Cock 2 Way 	 580

A header row is detected and skipped. MRP is optional — leave the column out to update names only. Existing MRP is never overwritten by a blank. Unknown SKUs are reported, not invented.

Export for publishing

Copy this JSON and paste it into the OVERRIDES object at the top of site/shop/assets/corsa-data.js, then redeploy. Your edits then apply for every visitor and no longer depend on this browser.
